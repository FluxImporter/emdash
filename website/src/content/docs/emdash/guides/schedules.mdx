## Before you start

- A saved template. See [Template format](/emdash/reference/template-format/).
- A URL source. If the feed needs a key, store it as a [credential](/emdash/guides/url-sources/).
- The `network:request:unrestricted` capability, granted on install. See [Permissions](/emdash/permissions/).

## Create the schedule

<Steps>

1. In the EmDash admin, open Flux Importer, then Schedules, and choose New schedule.
2. Pick the URL source and the template to import with.
3. Choose hourly, daily, weekly, or enter a cron expression.
4. Run a dry run to check the mapping, then save the schedule.

</Steps>

## Frequencies

Pick a preset, or type a five-field cron expression. The presets match these expressions:

<div class="fx-table" role="region" aria-label="Frequency presets" tabindex="0">

| Preset | Cron           | Runs                          |
| ------ | -------------- | ----------------------------- |
| Hourly | `0 * * * *`    | At minute 0 of every hour     |
| Daily  | `0 3 * * *`    | Every day at 03:00 UTC        |
| Weekly | `0 3 * * 1`    | Mondays at 03:00 UTC          |
| Custom | `*/15 * * * *` | Any five-field cron expression |

</div>

:::tip
Press <kbd>⌘</kbd> <kbd>K</kbd> anywhere in these docs to search for a route or a guide.
:::

## On Cloudflare Workers

Scheduled imports run on EmDash's Cron Trigger. The EmDash template sets one in `wrangler.jsonc`, for example:

```json title="wrangler.jsonc" {3-5}
{
  "name": "my-emdash-site",
  "triggers": {
    "crons": ["*/5 * * * *"]
  }
}
```

:::caution
Without a Cron Trigger, scheduled imports do not run. Manual imports still work.
:::

:::danger
Never put an API key in the feed URL. Anyone who can read the schedule can read the URL. Store the key as a credential.
:::
