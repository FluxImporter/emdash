Flux Importer for EmDash

Available · v0.7

Bring CSV, JSON, XML, Excel and ZIP files, and live URL feeds, into EmDash. Map columns in a visual wizard, preview a dry run, schedule repeats and roll back any run.

Requirements

  • EmDash 1.2 or later
  • Astro 6 or later
  • Node or Cloudflare Workers

Install in three steps

  1. 1

    Add the package

  2. 2

    Register the plugin

    Add fluxImporter() to the EmDash integration.

  3. 3

    Open the importer

    Start your site, sign in to the admin at /_emdash/admin and open Flux Importer. The wizard starts with your first file.
