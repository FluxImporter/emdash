Schedule a URL import

Fetch a feed on a timetable and import it with a saved template. Every scheduled run is logged and can be rolled back.

NoteSchedule times are in UTC.

Before you start

  • A saved template. See Template format.
  • A URL source. If the feed needs a key, store it as a credential.
  • The network:request:unrestricted capability, granted on install. See Permissions.
