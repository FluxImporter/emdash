# Flux Import M2a: workspace, verification and engine core — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the workspace and a local EmDash site, verify the undocumented EmDash APIs Milestone 2 depends on, and build the platform-independent engine (CSV reader, template, diff, job runner, log export) with full unit tests.

**Architecture:** The engine talks to EmDash only through small port interfaces (`ContentPort`, `SourcePort`, `KvCollection`). This plan builds and tests everything behind those ports with in-memory fakes. A second plan (M2b), written after Task 2's verification report, implements the ports against the real runtime, adds the plugin routes and the upload route, and runs integration tests on `sites/dev` and `workerd`.

**Why two plans:** The docs research (2026-10-07) found these M2 dependencies undocumented: `runtime.handleContentCreate/Update`, `SchemaRegistry.createField`, third-party `injectRoute` under `/_emdash/api` and its middleware, `hasPermission`, server-side lock reads, hidden fields, and `@emdash-cms/plugin-test` support for native plugins. `import:execute` is not a documented permission. Writing adapter code before reading the installed type declarations would be guessing.

**Tech Stack:** Node 22 (`.nvmrc` 22.23.1), pnpm workspace, TypeScript 5.x strict ESM, Vitest 4, Zod 4, Luxon 3, Biome 2 (lint and format), EmDash 1.2.0, Astro 6.

**Spec:** `docs/superpowers/specs/2026-10-07-flux-import-roadmap-design.md`

## Global Constraints

- Plugin ID `flux-import`. Exports `fluxImport()` and `fluxImportRoutes()`.
- Node `>=22.16` (EmDash engines). Run `nvm use` (reads `.nvmrc`) before any command.
- TypeScript strict, ESM, `import type` for types, `.js` extensions on internal imports.
- Never `eval` or `new Function`.
- The source-ID field is named `flux_source_id`.
- Batch size default 50, maximum 500. Time budget default 4,000 ms, checked between records.
- Job states: `created`, `running`, `paused`, `completed`, `cancelled`, `failed`.
- Record-level problems never fail the job; only unreadable input or a missing upload does.
- Template `version` is `1`; the format only grows additively.
- No AI attribution in commits or code (user rule): commit messages end at the body.
- Verification before done: `pnpm typecheck && pnpm lint && pnpm test` from the repo root.
- In this shell `cat` is an alias for `cat -n`. Write files with the editor tools or `command cat`, never `cat >`/`cat >>`, or every line gets a number prefix.

## Review Focus

1. A CSV with a UTF-8 BOM, CRLF line endings, quoted fields containing commas, quotes and newlines, and multibyte characters must parse identically whether read in one chunk or split at every byte, and resumed byte offsets must land exactly on record boundaries (Task 3).
2. Duplicate or blank header names must be rejected or named predictably, never silently overwrite each other's values (Task 3).
3. A crash after a content write but before the record is saved must not create a duplicate on resume (Task 7).
4. Two drivers calling `runBatch` concurrently on the same job must never process the same batch twice (Task 7).
5. Log CSV cells starting with `=`, `+`, `-`, `@`, tab or carriage return must be neutralised so the export is safe to open in a spreadsheet (Task 9).

### Task 3: Streaming CSV reader with byte offsets

The reader works on bytes, not decoded text, so every row carries exact byte offsets for resuming. This is safe for UTF-8 because the bytes for `"`, `,`, CR and LF never occur inside a multibyte sequence. Line endings are LF or CRLF; a bare CR outside quotes is ignored (old Mac line endings are unsupported, documented in M8).

**Files:**
- Create: `packages/flux-import/src/sources/csv.ts`
- Test: `packages/flux-import/tests/unit/csv.test.ts`, `packages/flux-import/tests/unit/helpers.ts`

```ts
export function streamOf(input: string | Uint8Array, chunkSize = 1 << 16): ReadableStream<Uint8Array> {
	const bytes = typeof input === "string" ? new TextEncoder().encode(input) : input;
	let i = 0;
	return new ReadableStream<Uint8Array>({
		pull(controller) {
			if (i >= bytes.length) {
				controller.close();
				return;
			}
			controller.enqueue(bytes.slice(i, i + chunkSize));
			i += chunkSize;
		},
	});
}

export async function collect<T>(it: AsyncIterable<T>): Promise<T[]> {
	const out: T[] = [];
	for await (const x of it) out.push(x);
	return out;
}
```

`packages/flux-import/src/sources/csv.ts`:
```ts
const QUOTE = 0x22;
const COMMA = 0x2c;
const CR = 0x0d;
const LF = 0x0a;
const BOM = [0xef, 0xbb, 0xbf];

export class CsvSyntaxError extends Error {
	constructor(
		message: string,
		readonly offset: number,
	) {
		super(message);
		this.name = "CsvSyntaxError";
	}
}

export interface CsvRow {
	fields: string[];
	start: number;
	end: number;
}

class ByteBuffer {
	private buf = new Uint8Array(256);
	length = 0;

	push(b: number): void {
		if (this.length === this.buf.length) {
			const next = new Uint8Array(this.buf.length * 2);
			next.set(this.buf);
			this.buf = next;
		}
		this.buf[this.length++] = b;
	}

	take(decoder: TextDecoder): string {
		const s = decoder.decode(this.buf.subarray(0, this.length));
		this.length = 0;
		return s;
	}
}

type State = "start" | "unquoted" | "quoted" | "quoteInQuoted";

export async function* parseCsvRows(
	stream: ReadableStream<Uint8Array>,
	startOffset = 0,
): AsyncGenerator<CsvRow> {
	const decoder = new TextDecoder("utf-8");
	const field = new ByteBuffer();
	let fields: string[] = [];
	let state: State = "start";
	let rowStart = startOffset;
	let rowHasContent = false;

	const endField = () => {
		fields.push(field.take(decoder));
	};

	const endRow = (end: number): CsvRow | null => {
		endField();
		const row = rowHasContent ? { fields, start: rowStart, end } : null;
		fields = [];
		rowStart = end;
		rowHasContent = false;
		state = "start";
		return row;
	};

	const feed = (b: number, p: number): CsvRow | null => {
		if (state === "quoted") {
			if (b === QUOTE) state = "quoteInQuoted";
			else field.push(b);
			return null;
		}
		if (state === "quoteInQuoted" && b === QUOTE) {
			field.push(QUOTE);
			state = "quoted";
			return null;
		}
		if (state === "start" && b === QUOTE) {
			state = "quoted";
			rowHasContent = true;
			return null;
		}
		if (b === COMMA) {
			endField();
			state = "start";
			rowHasContent = true;
			return null;
		}
		if (b === LF) return endRow(p + 1);
		if (b === CR) return null;
		field.push(b);
		state = "unquoted";
		rowHasContent = true;
		return null;
	};

	const reader = stream.getReader();
	const head: number[] = [];
	let pos = startOffset;
	try {
		for (;;) {
			const { done, value } = await reader.read();
			if (done) break;
			for (const b of value) {
				const p = pos++;
				if (startOffset === 0 && p < 3) {
					head.push(b);
					if (head.length < 3) continue;
					if (head.every((x, i) => x === BOM[i])) {
						rowStart = 3;
						continue;
					}
					for (let i = 0; i < head.length; i++) {
						const row = feed(head[i] as number, i);
						if (row) yield row;
					}
					continue;
				}
				const row = feed(b, p);
				if (row) yield row;
			}
		}
		if (head.length > 0 && head.length < 3) {
			for (let i = 0; i < head.length; i++) {
				const row = feed(head[i] as number, i);
				if (row) yield row;
			}
		}
		if (state === "quoted") throw new CsvSyntaxError("Unterminated quoted field", rowStart);
		const last = endRow(pos);
		if (last) yield last;
	} finally {
		await reader.cancel().catch(() => {});
	}
}

export interface CsvHeader {
	headers: string[];
	bodyOffset: number;
}

export function normalizeHeaders(raw: string[]): string[] {
	const seen = new Set<string>();
	return raw.map((h, i) => {
		const trimmed = h.trim();
		const name = trimmed === "" ? `column_${i + 1}` : trimmed;
		if (seen.has(name)) throw new CsvSyntaxError(`Duplicate header "${name}"`, 0);
		seen.add(name);
		return name;
	});
}

export async function readCsvHeader(stream: ReadableStream<Uint8Array>): Promise<CsvHeader> {
	for await (const row of parseCsvRows(stream, 0)) {
		return { headers: normalizeHeaders(row.fields), bodyOffset: row.end };
	}
	throw new CsvSyntaxError("CSV has no header row", 0);
}

export interface CsvRecord {
	seq: number;
	start: number;
	end: number;
	values: Record<string, string>;
	error?: "column_count";
}

export async function* readCsvRecords(
	stream: ReadableStream<Uint8Array>,
	opts: { headers: string[]; startOffset: number; startSeq: number },
): AsyncGenerator<CsvRecord> {
	let seq = opts.startSeq;
	for await (const row of parseCsvRows(stream, opts.startOffset)) {
		// fromEntries defines own properties, so a "__proto__" header stays plain data.
		const values = Object.fromEntries(opts.headers.map((h, i) => [h, row.fields[i] ?? ""]));
		const record: CsvRecord = { seq, start: row.start, end: row.end, values };
		if (row.fields.length !== opts.headers.length) record.error = "column_count";
		yield record;
		seq++;
	}
}

export function dropBytes(stream: ReadableStream<Uint8Array>, n: number): ReadableStream<Uint8Array> {
	let remaining = n;
	return stream.pipeThrough(
		new TransformStream<Uint8Array, Uint8Array>({
			transform(chunk, controller) {
				if (remaining >= chunk.length) {
					remaining -= chunk.length;
					return;
				}
				controller.enqueue(remaining > 0 ? chunk.subarray(remaining) : chunk);
				remaining = 0;
			},
		}),
	);
}
```

```ts
import { DateTime } from "luxon";
import { z } from "zod";

export const SOURCE_ID_FIELD = "flux_source_id";

const SLUG_RE = /^[a-z][a-z0-9_]{0,62}$/;
const NUMBER_RE = /^[+-]?(\d+\.?\d*|\.\d+)([eE][+-]?\d+)?$/;
const MAX_KEY_LENGTH = 256;
const MAX_SLUG_LENGTH = 200;

const column = z.string().min(1);
const timezone = z
	.string()
	.min(1)
	.refine((tz) => DateTime.now().setZone(tz).isValid, { message: "Unknown timezone" });

const fieldMapping = z.discriminatedUnion("type", [
	z.object({ from: column, type: z.literal("text") }).strict(),
	z.object({ from: column, type: z.literal("number") }).strict(),
	z
		.object({
			from: column,
			type: z.literal("date"),
			format: z.string().min(1).optional(),
			tz: timezone.default("UTC"),
		})
		.strict(),
]);

export const templateSchema = z
	.object({
		version: z.literal(1),
		collection: z.string().regex(SLUG_RE),
		locale: z.string().min(1),
		key: z.object({ from: column }).strict(),
		slug: z.object({ from: column }).strict().optional(),
		fields: z.record(z.string(), fieldMapping).superRefine((fields, ctx) => {
			const names = Object.keys(fields);
			if (names.length === 0) ctx.addIssue({ code: "custom", message: "Map at least one field" });
			for (const name of names) {
				if (!SLUG_RE.test(name)) {
					ctx.addIssue({ code: "custom", message: `Invalid field name "${name}"`, path: [name] });
				}
				if (name === SOURCE_ID_FIELD) {
					ctx.addIssue({ code: "custom", message: `"${SOURCE_ID_FIELD}" is reserved`, path: [name] });
				}
			}
		}),
	})
	.strict();

export type Template = z.infer<typeof templateSchema>;
type FieldMapping = Template["fields"][string];

export type FieldValue = string | number | null;
export type MappedRecord = { key: string; slug?: string; data: Record<string, FieldValue> };
export type ValueErrorCode =
	| "missing_key"
	| "key_too_long"
	| "invalid_number"
	| "invalid_date"
	| "empty_slug";
export type ValueError = { field: string; code: ValueErrorCode; message: string };

function cell(values: Record<string, string>, column: string): string {
	return Object.hasOwn(values, column) ? (values[column] ?? "") : "";
}

export function slugify(s: string): string {
	return s
		.normalize("NFKD")
		.replace(/[̀-ͯ]/g, "")
		.toLowerCase()
		.replace(/[^a-z0-9]+/g, "-")
		.replace(/^-+|-+$/g, "")
		.slice(0, MAX_SLUG_LENGTH)
		.replace(/-+$/, "");
}

function convert(
	mapping: FieldMapping,
	raw: string,
): { ok: true; value: FieldValue } | { ok: false; code: ValueErrorCode; message: string } {
	const trimmed = raw.trim();
	if (trimmed === "") return { ok: true, value: null };
	switch (mapping.type) {
		case "text":
			return { ok: true, value: raw };
		case "number":
			return NUMBER_RE.test(trimmed)
				? { ok: true, value: Number(trimmed) }
				: { ok: false, code: "invalid_number", message: `"${trimmed}" is not a number` };
		case "date": {
			const dt = mapping.format
				? DateTime.fromFormat(trimmed, mapping.format, { zone: mapping.tz })
				: DateTime.fromISO(trimmed, { zone: mapping.tz });
			if (!dt.isValid) {
				const expected = mapping.format ?? "ISO 8601";
				return { ok: false, code: "invalid_date", message: `"${trimmed}" is not a ${expected} date` };
			}
			return { ok: true, value: dt.toUTC().toISO() };
		}
	}
}

export function applyTemplate(
	t: Template,
	values: Record<string, string>,
): { ok: true; value: MappedRecord } | { ok: false; errors: ValueError[] } {
	const errors: ValueError[] = [];

	const key = cell(values, t.key.from).trim();
	if (key === "") {
		errors.push({ field: t.key.from, code: "missing_key", message: "The key column is empty" });
	} else if (key.length > MAX_KEY_LENGTH) {
		errors.push({
			field: t.key.from,
			code: "key_too_long",
			message: `Keys are limited to ${MAX_KEY_LENGTH} characters`,
		});
	}

	let slug: string | undefined;
	if (t.slug) {
		slug = slugify(cell(values, t.slug.from));
		if (slug === "") {
			errors.push({ field: "slug", code: "empty_slug", message: "The slug would be empty" });
		}
	}

	const data: Record<string, FieldValue> = {};
	for (const [field, mapping] of Object.entries(t.fields)) {
		const result = convert(mapping, cell(values, mapping.from));
		if (result.ok) data[field] = result.value;
		else errors.push({ field, code: result.code, message: result.message });
	}

	if (errors.length > 0) return { ok: false, errors };
	return { ok: true, value: slug === undefined ? { key, data } : { key, slug, data } };
}

export type SchemaField = { slug: string; type: string };

const COMPATIBLE: Record<FieldMapping["type"], string[]> = {
	text: ["string", "text", "url"],
	number: ["number", "integer"],
	date: ["datetime"],
};

export function checkTemplate(t: Template, fields: SchemaField[], headers: string[]): string[] {
	const errors: string[] = [];
	const columns = [t.key.from, ...(t.slug ? [t.slug.from] : []), ...Object.values(t.fields).map((m) => m.from)];
	for (const c of new Set(columns)) {
		if (!headers.includes(c)) errors.push(`Column "${c}" not found in the source`);
	}
	const byslug = new Map(fields.map((f) => [f.slug, f.type]));
	for (const [field, mapping] of Object.entries(t.fields)) {
		const type = byslug.get(field);
		if (type === undefined) {
			errors.push(`Field "${field}" does not exist in collection "${t.collection}"`);
		} else if (!COMPATIBLE[mapping.type].includes(type)) {
			errors.push(
				`Field "${field}" has type "${type}"; a ${mapping.type} mapping needs one of ${COMPATIBLE[mapping.type].join(", ")}`,
			);
		}
	}
	return errors;
}
```

```ts
import type { FieldValue, MappedRecord, Template } from "./template.js";

export type Change = { field: string; before: unknown; after: FieldValue };
export type PlanAction = "create" | "update" | "unchanged";
export type RecordPlan = { action: PlanAction; changes: Change[] };
export type CurrentEntry = { slug: string | null; data: Record<string, unknown> };

function same(before: unknown, after: FieldValue, isDate: boolean): boolean {
	const b = before ?? null;
	if (b === null || after === null) return b === after;
	if (isDate && typeof b === "string" && typeof after === "string") {
		const tb = Date.parse(b);
		return !Number.isNaN(tb) && tb === Date.parse(after);
	}
	return Object.is(b, after);
}

export function planRecord(
	current: CurrentEntry | null,
	next: MappedRecord,
	dateFields: ReadonlySet<string>,
): RecordPlan {
	const changes: Change[] = [];
	if (current === null) {
		if (next.slug !== undefined) changes.push({ field: "slug", before: null, after: next.slug });
		for (const [field, after] of Object.entries(next.data)) {
			if (after !== null) changes.push({ field, before: null, after });
		}
		return { action: "create", changes };
	}
	if (next.slug !== undefined && current.slug !== next.slug) {
		changes.push({ field: "slug", before: current.slug, after: next.slug });
	}
	for (const [field, after] of Object.entries(next.data)) {
		const before = Object.hasOwn(current.data, field) ? current.data[field] : null;
		if (!same(before, after, dateFields.has(field))) changes.push({ field, before: before ?? null, after });
	}
	return { action: changes.length === 0 ? "unchanged" : "update", changes };
}

export function dateFieldsOf(t: Template): Set<string> {
	return new Set(
		Object.entries(t.fields)
			.filter(([, m]) => m.type === "date")
			.map(([field]) => field),
	);
}
```

```ts
function matches(data: Record<string, unknown>, where: Where): boolean {
	return Object.entries(where).every(([k, cond]) => {
		const v = data[k];
		if (cond !== null && typeof cond === "object") {
			const c = cond as Record<string, unknown>;
			if ("in" in c) return (c.in as unknown[]).includes(v);
			if ("gte" in c && !((v as number) >= (c.gte as number))) return false;
			if ("gt" in c && !((v as number) > (c.gt as number))) return false;
			if ("lte" in c && !((v as number) <= (c.lte as number))) return false;
			if ("lt" in c && !((v as number) < (c.lt as number))) return false;
			return true;
		}
		return v === cond;
	});
}

export class MemoryKv<T> implements KvCollection<T> {
	readonly rows = new Map<string, { value: T; revision: number }>();
	private rev = 0;

	async get(id: string) {
		const row = this.rows.get(id);
		return row ? structuredClone(row.value) : null;
	}
	async put(id: string, data: T) {
		this.rows.set(id, { value: structuredClone(data), revision: ++this.rev });
	}
	async getVersioned(id: string) {
		const row = this.rows.get(id);
		return row ? { value: structuredClone(row.value), revision: String(row.revision) } : null;
	}
	async compareAndSet(id: string, expected: string | null, data: T) {
		const row = this.rows.get(id);
		const current = row ? String(row.revision) : null;
		if (current !== expected) return { applied: false as const };
		await this.put(id, data);
		return { applied: true as const, revision: String(this.rev) };
	}
	async query(opts: { where?: Where; orderBy?: Record<string, "asc" | "desc">; limit?: number; cursor?: string }) {
		let items = [...this.rows.entries()]
			.map(([id, r]) => ({ id, data: structuredClone(r.value) }))
			.filter((i) => matches(i.data as Record<string, unknown>, opts.where ?? {}));
		for (const [field, dir] of Object.entries(opts.orderBy ?? {}).reverse()) {
			items = items.sort((a, b) => {
				const av = (a.data as Record<string, number>)[field] as number;
				const bv = (b.data as Record<string, number>)[field] as number;
				return dir === "asc" ? av - bv : bv - av;
			});
		}
		const start = opts.cursor ? Number(opts.cursor) : 0;
		const limit = opts.limit ?? 50;
		const page = items.slice(start, start + limit);
		const hasMore = start + limit < items.length;
		return hasMore ? { items: page, cursor: String(start + limit), hasMore } : { items: page, hasMore };
	}
}

type StoredEntry = {
	id: string;
	locale: string;
	collection: string;
	slug: string | null;
	data: Record<string, unknown>;
	rev: number;
	pendingPublish: boolean;
};

export class FakeContent implements ContentPort {
	readonly entries = new Map<string, StoredEntry>();
	readonly locked = new Set<string>();
	readonly calls: string[] = [];
	sourceFieldEnsured = false;
	/** Called after a successful create or update; throw from it to simulate a crash. */
	afterWrite: (id: string) => void = () => {};
	/** Return a ContentWriteError to make a write with this data fail. */
	failWrite: (data: Record<string, unknown>) => ContentWriteError | null = () => null;
	/** Return a reason to make publishing this entry fail. */
	failPublish: (id: string) => "conflict" | "locked" | null = () => null;
	private next = 0;

	private snap(e: StoredEntry): EntrySnapshot {
		return {
			id: e.id,
			rev: String(e.rev),
			slug: e.slug,
			data: structuredClone(e.data),
			pendingPublish: e.pendingPublish,
		};
	}
	async get(collection: string, locale: string, id: string) {
		const e = this.entries.get(id);
		return e && e.collection === collection && e.locale === locale ? this.snap(e) : null;
	}
	async findBySourceId(collection: string, locale: string, sourceId: string) {
		this.calls.push(`find:${sourceId}`);
		for (const e of this.entries.values()) {
			if (e.collection === collection && e.locale === locale && e.data.flux_source_id === sourceId) {
				return this.snap(e);
			}
		}
		return null;
	}
	async isLocked(_c: string, _l: string, id: string) {
		return this.locked.has(id);
	}
	async create(input: { collection: string; locale: string; slug?: string; data: Record<string, unknown> }) {
		const failure = this.failWrite(input.data);
		if (failure) throw failure;
		const id = `e${++this.next}`;
		this.entries.set(id, {
			id,
			collection: input.collection,
			locale: input.locale,
			slug: input.slug ?? null,
			data: structuredClone(input.data),
			rev: 1,
			pendingPublish: true,
		});
		this.calls.push(`create:${id}`);
		this.afterWrite(id);
		return { id, rev: "1" };
	}
	async update(input: { id: string; rev: string; slug?: string; data: Record<string, unknown> }): Promise<WriteResult> {
		const e = this.entries.get(input.id);
		if (!e) throw new ContentWriteError("not_found", "Entry not found");
		if (this.locked.has(e.id)) return { ok: false, reason: "locked" };
		if (String(e.rev) !== input.rev) return { ok: false, reason: "conflict" };
		const failure = this.failWrite(input.data);
		if (failure) throw failure;
		e.data = { ...e.data, ...structuredClone(input.data) };
		if (input.slug !== undefined) e.slug = input.slug;
		e.rev++;
		e.pendingPublish = true;
		this.calls.push(`update:${e.id}`);
		this.afterWrite(e.id);
		return { ok: true, rev: String(e.rev) };
	}
	async publish(input: { id: string; rev: string }): Promise<WriteResult> {
		const e = this.entries.get(input.id);
		if (!e) throw new ContentWriteError("not_found", "Entry not found");
		const forced = this.failPublish(e.id);
		if (forced) return { ok: false, reason: forced };
		if (this.locked.has(e.id)) return { ok: false, reason: "locked" };
		if (String(e.rev) !== input.rev) return { ok: false, reason: "conflict" };
		e.pendingPublish = false;
		e.rev++;
		this.calls.push(`publish:${e.id}`);
		return { ok: true, rev: String(e.rev) };
	}
	async ensureSourceIdField() {
		this.sourceFieldEnsured = true;
	}
}

export class FakeSource implements SourcePort {
	readonly uploads = new Map<string, Uint8Array>();
	opens = 0;
	add(id: string, csv: string) {
		this.uploads.set(id, new TextEncoder().encode(csv));
	}
	async open(uploadId: string, offset: number) {
		const bytes = this.uploads.get(uploadId);

	}
}
```

```ts
export async function createJob(deps: EngineDeps, input: CreateJobInput): Promise<Job> {
	const batchSize = input.batchSize ?? BATCH_SIZE_DEFAULT;
	const budgetMs = input.budgetMs ?? BUDGET_MS_DEFAULT;
	if (!Number.isInteger(batchSize) || batchSize < 1 || batchSize > BATCH_SIZE_MAX) {
		throw new JobError("invalid_options", `batchSize must be an integer from 1 to ${BATCH_SIZE_MAX}`);
	}
	if (!Number.isInteger(budgetMs) || budgetMs < BUDGET_MS_MIN || budgetMs > BUDGET_MS_MAX) {
		throw new JobError("invalid_options", `budgetMs must be an integer from ${BUDGET_MS_MIN} to ${BUDGET_MS_MAX}`);
	}

	const parsed = templateSchema.safeParse(input.template);
	if (!parsed.success) {
		throw new JobError(
			"invalid_template",
			"The template is invalid",
			parsed.error.issues.map((i) => `${i.path.join(".") || "template"}: ${i.message}`),
		);
	}
	const template = parsed.data;

	let header: { headers: string[]; bodyOffset: number };
	try {
		header = await readCsvHeader(await deps.source.open(input.uploadId, 0));
	} catch (e) {
		if (e instanceof SourceMissingError || e instanceof CsvSyntaxError) {
			throw new JobError("invalid_source", e.message);
		}
		throw e;
	}

	const problems = checkTemplate(template, input.schemaFields, header.headers);
	if (problems.length > 0) {
		throw new JobError("invalid_template", "The template does not fit the source or schema", problems);
	}

	const now = new Date(deps.now()).toISOString();
	const job: Job = {
		id: deps.newId(),
		status: "created",
		uploadId: input.uploadId,
		template,
		dryRun: input.dryRun ?? false,
		publish: input.publish ?? true,
		batchSize,
		budgetMs,
		headers: header.headers,
		cursor: { offset: header.bodyOffset, seq: 0 },
		counters: emptyCounters(),
		lease: null,
		phase: "import",
		retryFromSeq: 0,
		schemaReady: false,
		error: null,
		createdAt: now,
		updatedAt: now,
	};
	const result = await deps.jobs.compareAndSet(job.id, null, job);
	if (!result.applied) throw new Error(`Job id ${job.id} already exists`);
	return job;
}

export async function updateJob(deps: EngineDeps, id: string, change: (job: Job) => Job): Promise<Job> {
	for (let attempt = 0; attempt < CAS_ATTEMPTS; attempt++) {
		const current = await deps.jobs.getVersioned(id);
		if (!current) throw new JobError("not_found", `Job ${id} not found`);
		const next = { ...change(current.value), updatedAt: new Date(deps.now()).toISOString() };
		const result = await deps.jobs.compareAndSet(id, current.revision, next);
		if (result.applied) return next;
	}
	throw new Error(`Job ${id} changed concurrently ${CAS_ATTEMPTS} times; try again`);
}

const ALLOWED: Record<"pause" | "resume" | "cancel" | "retry", JobStatus[]> = {
	pause: ["created", "running"],
	resume: ["paused", "failed"],
	cancel: ["created", "running", "paused", "failed"],
	retry: ["completed"],
};

export function transitionJob(
	deps: EngineDeps,
	id: string,
	action: "pause" | "resume" | "cancel" | "retry",
): Promise<Job> {
	return updateJob(deps, id, (job) => {
		if (!ALLOWED[action].includes(job.status) || (action === "retry" && job.dryRun)) {
			throw new JobError("invalid_transition", `Cannot ${action} a ${job.status}${job.dryRun ? " dry-run" : ""} job`);
		}
		switch (action) {
			case "pause":
				return { ...job, status: "paused" };
			case "resume":
				return { ...job, status: "running", error: null };
			case "cancel":
				return { ...job, status: "cancelled" };
			case "retry":
				return { ...job, status: "running", phase: "retry", retryFromSeq: 0, error: null };
		}
	});
}
```

**Interfaces:**
- Consumes: everything from Tasks 3 to 6. In particular `readCsvRecords`, `CsvRecord`, `CsvSyntaxError`; `applyTemplate`, `SOURCE_ID_FIELD`; `planRecord`, `dateFieldsOf`; `EngineDeps`, `Job`, `RecordRow`, `RecordStatus`, `recordKey`, `linkKey`; `ContentWriteError`, `SourceMissingError`; `JobError`, `updateJob`.
- Produces (from `src/engine/batch.ts`):
  - `runBatch(deps: EngineDeps, jobId: string, holder: string): Promise<Job>` — claims the lease, processes one bounded batch (import pass or retry pass), saves cursor and counters, releases the lease, and returns the saved job. Returns the job unchanged when it is not runnable or another holder has a live lease.
  - `LEASE_GRACE_MS = 30_000`
  - `processRecord(deps, job, rec, opts: { retry: boolean }): Promise<void>` (exported for Task 8)

Behaviour:
- **Claim:** runnable statuses are `created` and `running`. A lease is live while `expiresAt > now`. The claim sets `status: "running"` and `lease.expiresAt = now + budgetMs + LEASE_GRACE_MS` with compare-and-set; losing the race returns the stored job without work.
- **Schema:** before the first write of a non-dry-run job, call `content.ensureSourceIdField(collection)` once and set `schemaReady`.
- **Import pass:** open the source at `cursor.offset`, read records from `cursor.seq`, process each, advance the cursor to `{ offset: rec.end, seq: rec.seq + 1 }`, stop after `batchSize` records or when `now() - start >= budgetMs`. End of input sets `completed`.
- **Per record** (in `processRecord`):
  1. If a record row exists with a status other than `writing` (and this is not a retry), an interrupted batch already handled it: count it again and do nothing else. `release` saves cursor and counters together, so a record behind a saved cursor is never revisited; a revisit means the batch that handled it crashed before saving its counters.
  2. Column-count mismatch → `failed` with code `column_count`. Template errors → `failed` with the value errors.
  3. Resolve the entry: `links` by `linkKey`, then `content.get`. If none and the existing row is `writing`, call `content.findBySourceId` and repair the link.
  4. Plan with `planRecord`. Dry-run: save `planned` with `action` and `changes`; count `create`/`update`/`unchanged` into `created`/`updated`/`unchanged`.
  5. Plan `unchanged` and the row shows an unfinished write of this job (row status `writing`, or an error code starting with `publish_`) → the earlier write landed. With `job.publish` and `entry.pendingPublish`, publish it now with `entry.rev`. Status `created` if the row's `action` is `create`, else `updated`. This repairs a crash between write and publish, and is how a retry publishes after a failed publish.
  6. Otherwise `unchanged` → `unchanged` (an entry with someone else's pending draft is never published). Entry locked (`content.isLocked`) → `locked`.
  7. Save the row as `writing` with `action` (and `entryId` when updating), then `create` (data plus `flux_source_id`) and save the link, or `update` with the entry's `rev`. A write `{ ok: false, reason }` → that reason as status. With `job.publish`, call `content.publish` with the `rev` the write returned; a publish `{ ok: false, reason }` → that reason as status with error code `publish_conflict` or `publish_locked`. `ContentWriteError` → `failed` with its code. Any other error propagates and aborts the batch; the lease then expires and the next driver resumes.
  8. Save the final row (with `action`) and bump the counter for its status.
- **Release:** compare-and-set loop. If the stored lease is no longer ours, do not overwrite cursor or counters; return the stored job. If the stored status is still `running`, it becomes `completed` (end of input), `failed` (job-level error) or stays `running`. A `paused` or `cancelled` status set during the batch is kept. Clear the lease.
- **Job-level failures:** `SourceMissingError` → `failed` with code `source_missing`; `CsvSyntaxError` → `failed` with code `csv_syntax` and the byte offset in the message.

```ts
import { type CsvRecord, CsvSyntaxError, readCsvRecords } from "../sources/csv.js";
import { dateFieldsOf, type PlanAction, planRecord } from "./diff.js";
import { JobError } from "./jobs.js";
import { ContentWriteError, type EntrySnapshot, SourceMissingError } from "./ports.js";
import { applyTemplate, SOURCE_ID_FIELD } from "./template.js";
import {
	type Counters,
	type EngineDeps,
	type Job,
	linkKey,
	type RecordRow,
	recordKey,
} from "./types.js";

export const LEASE_GRACE_MS = 30_000;
const CAS_ATTEMPTS = 5;

type Outcome = { done: boolean; error?: { code: string; message: string } };
type RowFields = Omit<RecordRow, "jobId" | "seq" | "start" | "end" | "updatedAt">;

const iso = (deps: EngineDeps) => new Date(deps.now()).toISOString();

function counterFor(row: RowFields): keyof Counters | null {
	switch (row.status) {
		case "planned":
			return row.action === "create" ? "created" : row.action === "update" ? "updated" : "unchanged";
		case "writing":
			return null;
		default:
			return row.status;
	}
}

async function claim(deps: EngineDeps, jobId: string, holder: string): Promise<{ ok: boolean; job: Job }> {
	const current = await deps.jobs.getVersioned(jobId);
	if (!current) throw new JobError("not_found", `Job ${jobId} not found`);
	const job = current.value;
	const now = deps.now();
	if (job.status !== "created" && job.status !== "running") return { ok: false, job };
	if (job.lease && job.lease.holder !== holder && job.lease.expiresAt > now) return { ok: false, job };
	const next: Job = {
		...job,
		status: "running",
		lease: { holder, expiresAt: now + job.budgetMs + LEASE_GRACE_MS },
		updatedAt: iso(deps),
	};
	const result = await deps.jobs.compareAndSet(jobId, current.revision, next);
	if (!result.applied) return { ok: false, job: (await deps.jobs.get(jobId)) ?? job };
	return { ok: true, job: next };
}

async function release(deps: EngineDeps, job: Job, holder: string, outcome: Outcome): Promise<Job> {
	for (let attempt = 0; attempt < CAS_ATTEMPTS; attempt++) {
		const current = await deps.jobs.getVersioned(job.id);
		if (!current) throw new JobError("not_found", `Job ${job.id} not found`);
		const stored = current.value;
		if (stored.lease?.holder !== holder) return stored;
		let status = stored.status;
		if (status === "running") status = outcome.error ? "failed" : outcome.done ? "completed" : "running";
		const finishedRetry = outcome.done && job.phase === "retry";
		const next: Job = {
			...stored,
			status,
			cursor: job.cursor,
			counters: job.counters,
			schemaReady: job.schemaReady,
			phase: finishedRetry ? "import" : job.phase,
			retryFromSeq: job.retryFromSeq,
			error: outcome.error ?? stored.error,
			lease: null,
			updatedAt: iso(deps),
		};
		const result = await deps.jobs.compareAndSet(job.id, current.revision, next);
		if (result.applied) return next;
	}
	throw new Error(`Could not save job ${job.id} after ${CAS_ATTEMPTS} attempts`);
}

export async function processRecord(
	deps: EngineDeps,
	job: Job,
	rec: CsvRecord,
	opts: { retry: boolean },
): Promise<void> {
	const key = recordKey(job.id, rec.seq);
	const existing = await deps.records.get(key);
	if (existing && existing.status !== "writing" && !opts.retry) {
		// Only reached after a crash: the batch that wrote this row never saved its cursor and counters.
		const counter = counterFor(existing);
		if (counter) job.counters[counter]++;
		return;
	}

	const base = { jobId: job.id, seq: rec.seq, start: rec.start, end: rec.end };
	const save = (fields: RowFields) => deps.records.put(key, { ...base, ...fields, updatedAt: iso(deps) });

	const row = await decide(deps, job, rec, existing, save);
	await save(row);
	if (existing && opts.retry) {
		const old = counterFor(existing);
		if (old) job.counters[old]--;
	}
	const counter = counterFor(row);
	if (counter) job.counters[counter]++;
}

async function decide(
	deps: EngineDeps,
	job: Job,
	rec: CsvRecord,
	existing: RecordRow | null,
	save: (fields: RowFields) => Promise<void>,
): Promise<RowFields> {
	if (rec.error) {
		return {
			status: "failed",
			sourceKey: null,
			entryId: null,
			errors: [{ code: "column_count", message: `Expected ${job.headers.length} columns` }],
		};
	}
	const mapped = applyTemplate(job.template, rec.values);
	if (!mapped.ok) return { status: "failed", sourceKey: null, entryId: null, errors: mapped.errors };

	const { key: sourceKey, slug, data } = mapped.value;
	const { collection, locale } = job.template;
	const linkId = linkKey(collection, locale, sourceKey);

	let entry: EntrySnapshot | null = null;
	const link = await deps.links.get(linkId);
	if (link) entry = await deps.content.get(collection, locale, link.entryId);
	const recovering = existing?.status === "writing";
	if (!entry && recovering) {
		entry = await deps.content.findBySourceId(collection, locale, sourceKey);
		if (entry) await deps.links.put(linkId, { collection, locale, sourceKey, entryId: entry.id });
	}

	const plan = planRecord(entry, mapped.value, dateFieldsOf(job.template));
	const entryId = entry?.id ?? null;
	if (job.dryRun) return { status: "planned", sourceKey, entryId, action: plan.action, changes: plan.changes };

	const publishFailed = (reason: "conflict" | "locked", id: string, action: PlanAction | undefined): RowFields => ({
		status: reason,
		sourceKey,
		entryId: id,
		...(action ? { action } : {}),
		errors: [
			{
				code: `publish_${reason}`,
				message:
					reason === "locked"
						? "Saved as a draft: the entry is locked, so it was not published"
						: "Saved as a draft: the entry changed before it could be published",
			},
		],
	});

	if (entry && plan.action === "unchanged") {
		const unfinished =
			existing !== null &&
			(existing.status === "writing" || (existing.errors ?? []).some((e) => e.code.startsWith("publish_")));
		if (!unfinished) return { status: "unchanged", sourceKey, entryId };
		const action = existing?.action;
		if (job.publish && entry.pendingPublish) {
			const published = await deps.content.publish({ collection, locale, id: entry.id, rev: entry.rev });
			if (!published.ok) return publishFailed(published.reason, entry.id, action);
		}
		return { status: action === "create" ? "created" : "updated", sourceKey, entryId, ...(action ? { action } : {}) };
	}
	if (entry && (await deps.content.isLocked(collection, locale, entry.id))) {
		return { status: "locked", sourceKey, entryId };
	}

	await save({ status: "writing", sourceKey, entryId, action: plan.action });
	const slugPart = slug === undefined ? {} : { slug };
	try {
		let written: { id: string; rev: string };
		if (!entry) {
			const created = await deps.content.create({
				collection,
				locale,
				...slugPart,
				data: { ...data, [SOURCE_ID_FIELD]: sourceKey },
			});
			await deps.links.put(linkId, { collection, locale, sourceKey, entryId: created.id });
			written = created;
		} else {
			const result = await deps.content.update({ collection, locale, id: entry.id, rev: entry.rev, ...slugPart, data });
			if (!result.ok) return { status: result.reason, sourceKey, entryId, action: plan.action };
			written = { id: entry.id, rev: result.rev };
		}
		if (job.publish) {
			const published = await deps.content.publish({ collection, locale, id: written.id, rev: written.rev });
			if (!published.ok) return publishFailed(published.reason, written.id, plan.action);
		}
		return {
			status: plan.action === "create" ? "created" : "updated",
			sourceKey,
			entryId: written.id,
			action: plan.action,
			changes: plan.changes,
		};
	} catch (e) {
		if (e instanceof ContentWriteError) {
			return { status: "failed", sourceKey, entryId, action: plan.action, errors: [{ code: e.code, message: e.message }] };
		}
		throw e;
	}
}

async function importPass(deps: EngineDeps, job: Job, started: number): Promise<Outcome> {
	const stream = await deps.source.open(job.uploadId, job.cursor.offset);
	let processed = 0;
	for await (const rec of readCsvRecords(stream, {
		headers: job.headers,
		startOffset: job.cursor.offset,
		startSeq: job.cursor.seq,
	})) {
		await processRecord(deps, job, rec, { retry: false });
		job.cursor = { offset: rec.end, seq: rec.seq + 1 };
		processed++;
		if (processed >= job.batchSize || deps.now() - started >= job.budgetMs) return { done: false };
	}
	return { done: true };
}

export async function runBatch(deps: EngineDeps, jobId: string, holder: string): Promise<Job> {
	const claimed = await claim(deps, jobId, holder);
	if (!claimed.ok) return claimed.job;
	const job = claimed.job;
	const started = deps.now();
	let outcome: Outcome;
	try {
		if (!job.dryRun && !job.schemaReady) {
			await deps.content.ensureSourceIdField(job.template.collection);
			job.schemaReady = true;
		}
		outcome = job.phase === "retry" ? await retryPass(deps, job, started) : await importPass(deps, job, started);

		if (e instanceof SourceMissingError) {
			outcome = { done: false, error: { code: "source_missing", message: e.message } };
		} else if (e instanceof CsvSyntaxError) {
			outcome = { done: false, error: { code: "csv_syntax", message: `${e.message} at byte ${e.offset}` } };
		} else {
			throw e;
		}
	}
	return release(deps, job, holder, outcome);
}
```

```ts
import type { EngineDeps, RecordRow, RecordStatus } from "./types.js";

export const LOG_COLUMNS = [
	"record",
	"status",
	"source_key",
	"entry_id",
	"action",
	"error_code",
	"error_field",
	"message",
] as const;

const PAGE = 100;

export function csvCell(value: unknown): string {
	let s = value === null || value === undefined ? "" : String(value);
	if (/^[=+\-@\t\r]/.test(s)) s = `'${s}`;
	if (/[",\r\n]/.test(s) || s !== s.trim()) s = `"${s.replace(/"/g, '""')}"`;
	return s;
}

export function recordsToCsvLines(rows: RecordRow[]): string {
	return rows
		.map((r) => {
			const first = r.errors?.[0];
			return [
				r.seq + 1,
				r.status,
				r.sourceKey,
				r.entryId,
				r.action,
				first?.code,
				first?.field,
				r.errors?.map((e) => e.message).join("; "),
			]
				.map(csvCell)
				.join(",");
		})
		.map((line) => `${line}\r\n`)
		.join("");
}

export async function buildLogCsv(
	deps: EngineDeps,
	jobId: string,
	opts: { status?: RecordStatus } = {},
): Promise<string> {
	let out = `${LOG_COLUMNS.join(",")}\r\n`;
	const where = opts.status ? { jobId, status: opts.status } : { jobId };
	let cursor: string | undefined;
	do {
		const page = await deps.records.query({
			where,
			orderBy: { seq: "asc" },
			limit: PAGE,
			...(cursor ? { cursor } : {}),
		});
		out += recordsToCsvLines(page.items.map((i) => i.data));
		cursor = page.hasMore ? page.cursor : undefined;
	} while (cursor);
	return out;
}
```
