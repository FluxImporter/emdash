### Plan Rulings 1-20, and what the code does now

1. **`jobs/summaries`, a new read-only route; `jobs/list` unchanged** (Fact D1). `JOB_SUMMARIES_INPUT`

   tool answer as before. Confirmed by the acceptance run (Review Focus 5).
2. **The filter is the `["dryRun", "createdAt"]` index**, queried with the boolean as is: V2 held on

   at the first scheduler tick (V3); `home.test.ts` and the parity `it` check it on both hosts.
3. **`JobListItem`** holds what the table and its actions need: no template, cursor, lease holder,
