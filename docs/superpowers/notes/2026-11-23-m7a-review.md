## Rulings

### Plan Rulings 1-17, and what the code does now

1. **The `flux_source_id` widget.** Coordinator's answer (2026-11-23): yes. `ensureSourceIdField`
   (`src/emdash/schema.ts`) passes `widget: "flux-import:source-id"` to `createField` and sets it
   with `updateField` on an existing field that has none; another widget, or `""`, is never
   overwritten. `index.tsx` exports `fields: { "source-id": SourceIdField }`, read-only and
   collapsed, "No import ID" for an empty value. Confirmed by the acceptance run (V3). Spec
   amendment 1.
2. **Messages beside their components; `useT()` interpolates English.** Each folder's
   `messages.ts`; `translate` calls `i18n._` only for an ID in `i18n.messages`, else
   `interpolate` (`src/admin/i18n.ts`). `useT` re-binds on the provider's `_`, so a locale change
   re-renders. Spec amendment 2.
3. **Route errors from the envelope.** `readError` and `ApiError(code, message, status, details?)`
   (`src/admin/api-error.ts`); `describeError` maps codes to sentences, any 401 to the session
   sentence and a 403 (other than `CSRF_REJECTED`) to the administrators-only one, and shows the
   route's redacted message only for unknown codes and four allow-listed ones without
   `problems`. Spec amendment 3.
4. **The log through `apiFetch`, a `Blob` and an object URL** (`downloadLog`, `src/admin/api.ts`),
   revoked after the click. Confirmed (V6). Spec amendment 4.
5. **The schema from the manifest and the schema API** (`src/admin/queries.ts`). Spec
   amendment 5.
6. **Raw samples in the panel, conversions in Preview.** Spec amendment 6.
7. **Every source an upload ID** (`SourceStep` and its tabs). Spec amendment 7.
8. **Mirrored constants and `resolvePath`**, pinned by `admin-limits.test.ts` and
   `admin-sample.test.ts`; Task 8 added the engine's boolean tokens, separator defaults and the
   grammar's token caps. Spec amendment 8.
9. **Admin CSS classes only**, enforced by `admin-boundary.test.ts` through the TypeScript AST.
   The review adds the caveat about Kumo's own classes. Spec amendment 9.
10. **`@dnd-kit/core` and `@dnd-kit/utilities` as `dependencies`** with the admin's caret ranges;
    no `@dnd-kit/sortable`.
11. **Routes mocked beneath `apiFetch`** (`tests/admin/harness.tsx`'s `mockRoutes`, which fails
    any request without the CSRF header, and fakes the upload's XHR). Spec amendment 10.
12. **The URL with `history.replaceState(history.state, …)`** (`src/admin/wizard/url.ts`); nothing
    is pushed. The URL is read once at mount (Open issues).
13. **Template-save timing**, with `saveOffered(state)` deciding what Run may save (Task 15 found
    Run saving an un-offered template). Spec amendment 11.
14. **Run-driver policy**: `RETRY_DELAYS_MS = [1000, 3000, 9000]`, `LEASE_WAIT_MS = 2000`,
    `IDLE_WAIT_MS = 500` (`src/admin/run-driver.ts`); any non-null `lease` in a reply is another
    holder's. Confirmed (Review Focus 1). Spec amendment 12.
15. **The derived owner** (`deriveOwner`, `src/admin/wizard/state.ts`), with the fallback kept to
    `OWNER_PATTERN`'s characters. Confirmed: `wizard-posts-en`. Spec amendment 13.
16. **The fixed schedule date** as a constant JSONata `expr` with `tz: "site"`. Spec amendment 14.
